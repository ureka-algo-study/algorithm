## 풀이 정보

| 항목          | 내용                                           |
| ------------- | ---------------------------------------------- |
| 문제 링크     | [키로거](https://www.acmicpc.net/problem/5397) |
| 플랫폼        | 백준                                           |
| 알고리즘 유형 | 스택, 연결 리스트                              |
| 난이도        | 백준 실버2                                     |
| 사용 언어     | Node.js (javascript)                           |

---

## 풀이 핵심 포인트

> cursor 위치를 기준으로 left 스택 배열, right 스택 배열로 분리하여 값을 넣어줬습니다.

- ***

## 고민했던 점

> 처음에 string을 slice를 반복적으로 사용해서 풀었더니, 문자열 전체를 새로 복사해서 O(N) 메모리가 매 연산마다 생기는 문제가 있었습니다.
> 그래서 left 스택 배열, cursor, right 스택 배열로 나누어서 생각하여 풀었습니다.

- ***

## 시간/공간 복잡도 (선택)

- 시간 복잡도: `O(N)`
- 공간 복잡도: `O(N)`
